# Contributing

PRs are welcome — including AI-assisted ones. Using Claude, Copilot, ChatGPT or similar
tools to write or review your change is fine.

What matters is the same either way:

- You understand the change and can answer questions about it.
- Describe how you tested it (and say so if something couldn't be tested live).
- Keep PRs focused; one fix or feature per PR is easiest to review.
